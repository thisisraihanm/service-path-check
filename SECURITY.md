# Handling sensitive evidence

These tools run locally and do not upload reports. Reports can contain hostnames, addresses, configuration details, paths, and file hashes. Keep operational reports and snapshots out of public repositories. Example data is fictional.

Use only endpoints and files you are authorized to inspect. No tool changes network settings, restarts services, deletes files, or repairs backups.

For a security issue, open a minimal issue without secrets or production evidence. Request a private reporting channel before sharing sensitive details.
