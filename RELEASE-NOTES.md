# Easy Windows app 1.1.0

Download **ServicePathCheck-Windows.zip** under Assets, right-click it, choose **Extract All**, and open **ServicePathCheck.exe**.

Python is included. No terminal commands or configuration-file editing are required. Start with **Try a safe example**, then use the guided screen. Results explain what happened and what to do next; detailed reports are available for IT.

The app reads and reports. It does not repair settings, copy backups, or delete files. The Windows app is not code-signed; an organization may require IT approval. Settings collection respects the current PowerShell script policy.

The Windows build checks the source desktop window and the packaged app before creating this archive. Matching backup contents still need a restore test; successful connection checks do not establish full application health.
